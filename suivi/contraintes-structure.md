## Points signalés dans le document

- **Exemple d’écart** : le cours écrit « Écart : +60°€ (+15) » ; le calcul donne +600 € (+15 %). La page calcule l’écart à partir des montants (4 000 € prévus, 4 600 € réels).
- **Consommation moyenne** : « 180  30 = 6 kg/jour », le signe ÷ manque ; la page écrit la division.
- Le titre du fichier est tronqué (« …caractéristiques d.docx ») ; le titre du document est « …d’une structure ».
- Le calculateur des indicateurs utilise, pour l’essai, des montants du budget du restaurant diététique ; le **stock moyen** (3 000 €) n’est pas donné par le cours, la page le dit.
- Le cours ne donne pas de formule pour le point mort (seulement sa définition) : pas de calcul sur la page.
- Coquilles mineures non reprises : « en vus de », « deces », « de al consommation », « peur être », « tables » pour « stables », « plsu », « invertir ».
