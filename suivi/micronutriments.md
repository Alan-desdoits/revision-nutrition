## Remarques

- Absorption du fer : deux chiffres différents dans le cours (voir `suivi/README.md`). La page affiche ceux du tableau (20–30 % / 5–10 %).
- B12 : l'exemple d'aliments du cours vise 2,4 µg alors que l'apport conseillé est de 4 µg. Les deux sont repris tels quels.
- Le soufre n'a pas d'apport chiffré dans le cours.
